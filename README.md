# 📅 Ftracker - Calendario Familiar y Tracker de Hábitos 2026 - 2027

Aplicación web móvil-first para la gestión del calendario familiar y seguimiento de retos diarios.

## 🚀 Características

- **Vista Mensual Touch-Optimized**: Cuadrícula de un solo mes con pestañas deslizables para navegar entre los meses de 2026 y 2027.
- **Detalle de Actividades Integrado**: Lista de eventos del mes justo debajo del calendario, con filtro por día al tocar celdas.
- **🎯 Retos Diarios Gamificados**:
  - Dieta Cumplida
  - Ejercicio Realizado
  - Métricas en tiempo real de éxitos vs. días transcurridos del mes.
  - Barras de progreso dinámicas e insignias por niveles (Leyenda, Pro, En Marcha).
- **🔔 Integración con Google Calendar**: Botón directo para crear recordatorios en Google Calendar.
- **💾 Almacenamiento Local y Exportación/Importación**: Persistencia automática en `localStorage` con soporte completo de backup JSON.
